# Common Phrasal Verbs with Hindi Meaning & Daily-Life Examples

| Phrasal Verb | Meaning (Hindi) | English Example | Hindi Meaning |
|---|---|---|---|
| **Take off** | उतारना | Take off your shoes. | अपने जूते उतारो। |
|  | उड़ान भरना | The plane took off on time. | विमान समय पर उड़ गया। |
|  | जल्दी चले जाना | He took off without saying goodbye. | वह बिना अलविदा कहे चला गया। |
|  | बहुत सफल होना | Her YouTube channel took off. | उसका यूट्यूब चैनल बहुत सफल हो गया। |
|  | छुट्टी लेना | I'm taking tomorrow off. | मैं कल छुट्टी ले रहा हूँ। |
| **Take out** | बाहर निकालना | Take out your phone. | अपना फोन बाहर निकालो। |
|  | कचरा बाहर फेंकना | Please take out the trash. | कृपया कचरा बाहर फेंक दो। |
|  | ATM से पैसे निकालना | I took out ₹500 from the ATM. | मैंने ATM से ₹500 निकाले। |
|  | बाहर घुमाने/खाने ले जाना | He took me out for dinner. | वह मुझे डिनर पर ले गया। |
|  | खत्म करना/मार गिराना | The police took out the criminal. | पुलिस ने अपराधी को मार गिराया। |
| **Put down** | नीचे रखना | Put down your bag. | अपना बैग नीचे रखो। |
|  | लिख लेना | Put down your name here. | यहाँ अपना नाम लिख दो। |
|  | किसी को नीचा दिखाना | Don't put others down. | दूसरों को नीचा मत दिखाओ। |
|  | बच्चे को सुलाना | She put the baby down. | उसने बच्चे को सुला दिया। |
| **Pick up** | उठाना | Pick up the pen. | पेन उठाओ। |
|  | लेने जाना | I'll pick you up at 6. | मैं तुम्हें 6 बजे लेने आऊँगा। |
|  | फोन उठाना | Please pick up the call. | कृपया फोन उठाओ। |
|  | सीख लेना | I picked up English at work. | मैंने काम करते-करते अंग्रेज़ी सीख ली। |
|  | खरीद लेना | Pick up some bread. | थोड़ी ब्रेड खरीद लेना। |
|  | सुधार होना | Business picked up this month. | इस महीने कारोबार बेहतर हुआ। |
| **Put in** | अंदर रखना | Put the milk in the fridge. | दूध फ्रिज में रख दो। |
|  | मेहनत करना | You need to put in more effort. | तुम्हें और मेहनत करनी होगी। |
|  | आवेदन देना | I put in my job application. | मैंने नौकरी के लिए आवेदन दिया। |
|  | लगाना/इंस्टॉल करना | They put in a new AC. | उन्होंने नया AC लगवाया। |
| **Put on** | पहनना | Put on your jacket. | अपनी जैकेट पहन लो। |
|  | चालू करना | Put on the TV. | टीवी चालू करो। |
|  | वजन बढ़ना | He has put on weight. | उसका वजन बढ़ गया है। |
|  | आयोजन करना | They are putting on a show. | वे एक शो आयोजित कर रहे हैं। |
|  | दिखावा करना | Don't put on a fake smile. | नकली मुस्कान मत दिखाओ। |
|  | लगाना (क्रीम आदि) | Put on some sunscreen. | थोड़ा सनस्क्रीन लगा लो। |

## Easy Daily-Life Sentences

- **Take off** your helmet. → अपना हेलमेट उतारो।
- **Take out** your ID card. → अपना आईडी कार्ड बाहर निकालो।
- **Put down** your phone. → अपना फोन नीचे रखो।
- **Pick up** your keys. → अपनी चाबियाँ उठाओ।
- **Put in** your PIN. → अपना PIN डालो।
- **Put on** your seat belt. → अपनी सीट बेल्ट बाँध लो।
